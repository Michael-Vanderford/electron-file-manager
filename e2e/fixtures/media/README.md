# Synthetic media fixtures

These are original, tiny test assets generated locally, not downloaded artwork.

- `still.jpg`: 32 × 24 navy/cyan gradient, JPEG.
- `still.webp`: 32 × 24 navy/cyan gradient, WebP.
- `animated.gif`: two 32 × 24 red/blue frames, 100 ms/frame, looping.
- `clip.webm`: 32 × 24 blue frames, VP8, approximately 0.3 seconds, no audio.

Recreate with ImageMagick and FFmpeg:

```sh
convert -size 32x24 gradient:navy-cyan still.jpg
convert -size 32x24 gradient:navy-cyan still.webp
convert -delay 10 -size 32x24 xc:red -size 32x24 xc:blue -loop 0 animated.gif
ffmpeg -f lavfi -i color=c=blue:s=32x24:d=0.3 -c:v libvpx -an clip.webm
```

The tests themselves use the committed bytes and do not need these generators installed. PNG/SVG fixtures are generated by existing test helpers. A valid XCF fixture remains a documented compatibility gap.
